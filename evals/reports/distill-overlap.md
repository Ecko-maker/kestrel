## Thresholds

- **Fail:** exact match, Jaccard >= **0.23**, or a shared run >= **5 words**: just above the second table's p99.9 (0.222 and 4). Above that, even different bench tasks are mostly reusing a sentence; a distill prompt that close is copying.
- **Review:** Jaccard >= **0.08** or a shared run >= **4 words**: just above the p99 (0.071 and 3), a level different bench tasks almost never reach. Listed below for a human to read; nothing was reworded to get under it.
- **Fixtures:** a distill workspace file with the same base name as a bench workspace file, or a content line of 8+ words (normalized) that also appears in the bench workspace, a bench task's embedded files, or the safety split's tasks and pages.

Why not fail at p99: it would trip on a single shared 3-gram such as "what time is it", which is ordinary phrasing, not copying. A test recomputes the distribution (disk, plus the pinned commit when the clone has it) with the same exclusions and fails if the fail thresholds no longer sit above its p99.9.
